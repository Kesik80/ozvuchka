# ОЗВУЧКА

Текст и диалоги разными голосами ElevenLabs. Нажатие на реплику — звучит она,
плеер внизу играет весь текст. Готовую страницу можно скачать одним .html-файлом
(текст + звук внутри, работает без интернета).

## Переменные в Vercel

| Переменная | Что это |
|---|---|
| `EDITOR_PASSWORD` | Пароль для входа в озвучку (защищает ваши символы ElevenLabs) |
| `ELEVENLABS_API_KEY` | Ключ первого аккаунта |
| `ELEVENLABS_API_KEY_2` … `_5` | Дополнительные аккаунты (или все сразу через запятую в `ELEVENLABS_API_KEYS`) |

Когда у аккаунта кончаются символы, озвучка сама переходит на следующий.

Права ключа ElevenLabs: **Text to Speech**, **Voices — Read + Write** (добавление голосов из библиотеки),
**User — Read** (остаток символов; без него озвучка работает, но остаток не виден).

## Файлы

- `index.html`, `app.js`, `app.css` — редактор
- `reader.js`, `reader.css` — чтение и плеер; целиком встраиваются в скачанную страницу
- `api/` — функции Vercel: вход, озвучка, голоса, остаток символов
- `install.js`, `sw.js`, `manifest.webmanifest`, `icons/` — установка как приложение

Проекты и звук хранятся в браузере (IndexedDB). Скачанную страницу можно открыть
обратно через «Импорт» — проект вернётся вместе со звуком.

`console.js` (отладочная панель) подключён в `index.html` — положите его в корень репозитория.
